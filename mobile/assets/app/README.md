# Assets nativos de la app

Assets oficiales activos en `app.json`:

- `Bite-Club-_icon.png` — ícono principal iOS/Android (1024×1024, opaco).
- `Bite-Club-_adaptive-icon.png` — foreground del adaptive icon Android (1024×1024, transparente).
- `Bite-Club-_monochrome-icon.png` — icono monocromático Android (1024×1024).
- `Bite-Club-_favicon.png` — favicon web (512×512).
- `Bite-Club-_splash-logo-static.png` — logo del splash nativo (1200×1200).
- `splash-animation.mp4` — animación de entrada reproducida con `expo-video`.

El fondo del adaptive icon es `#E41A17` y el splash nativo usa fondo `#FFFFFF`.
