# icons/ — Iconografía custom de marca (si hace falta)

Vacía por ahora. La iconografía de uso general (navegación, acciones de UI) se resuelve
con `@expo/vector-icons` (familia Feather — ver `docs/DESIGN_SYSTEM.md`, sección
"Iconografía"), sin necesitar archivos aquí.

Esta carpeta queda reservada solo para el caso en que Bite Club necesite un ícono custom
que no exista en esa librería (por ejemplo, un ícono de marca muy específico) — se agrega
aquí únicamente cuando ese caso aparezca, no de forma preventiva.
