# products/ — Fotografías reales de productos

Vacía por ahora. Contenido dinámico futuro (ver `docs/DESIGN_SYSTEM.md`, sección
"Assets permanentes vs. contenido dinámico"): fotografías de productos (B's Bite, Sweet
Bite, Cheesy Bite, Mordida Nica, Croqueta Bites, Papas Bravas, etc.).

Durante la fase de frontend con datos mock, estas imágenes se referencian localmente
desde aquí. Más adelante, cuando se conecte el backend, las fotos de producto pasarán a
administrarse desde Supabase Storage y este directorio dejará de ser la fuente de verdad.
