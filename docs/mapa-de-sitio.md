# Mapa de sitio — Bite Club

## Navegación principal (tab bar)

- **Inicio** → banners promocionales, accesos rápidos, últimos pedidos
- **Club** → puntos, identificación del usuario, catálogo de recompensas
- **Pedir** → flujo de pedido (entrega / retiro / programado)
- **Ofertas** → catálogo de combos con precio y horario de validez
- **Más** → cuenta, notificaciones, soporte, información, cerrar sesión

Este documento es la referencia funcional para diseñar las pantallas reales en la
siguiente fase (Design System → mockups → implementación). Los nombres de sección son
propios de Bite Club; no se usa nomenclatura de ninguna marca de terceros.
