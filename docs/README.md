# docs — Documentación funcional y técnica

## Contenido

- `mapa-de-sitio.md` — estructura de navegación oficial de Bite Club
- `decisiones-tecnicas.md` — registro de decisiones de stack y por qué se tomaron
- `security-review.md` — hallazgos de seguridad pendientes sobre el esquema de Supabase
- `fases.md` — plan de fases del proyecto y estado actual

Esta carpeta crece a medida que avanza el proyecto. Cada decisión importante (cambio de
librería, cambio de proveedor, cambio de arquitectura) debe quedar registrada aquí para
que el equipo (y ChatGPT, en su rol de auditoría) tenga contexto sin depender de memoria
de conversaciones pasadas.
